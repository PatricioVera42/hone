# JSON-RPC over a local WebSocket between app and host

The app and the host (ADR 0004) talk JSON-RPC 2.0 over a WebSocket: requests with ids and matching responses, plus notifications such as "file changed" or terminal output. We chose a standard over an ad-hoc message format so request/response pairing and error reporting come for free, and because it's the same protocol LSP uses, which Hone will speak later. The host only listens on localhost and requires a token generated by the app at launch, since anything that can reach it can run commands on the user's machine.
