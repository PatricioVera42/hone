# CaskaydiaCove Nerd Font Mono

The terminal's and code editors' font: Cascadia Code 2407.24 patched with Nerd Font icons, from the
[Nerd Fonts v3.5.1 release](https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1) (`CascadiaCode.zip`).
The four files here are its Mono Regular, Bold, Italic and Bold Italic TTFs converted to WOFF2, unchanged otherwise.
They're licensed under the SIL Open Font License 1.1, in `LICENSE`.
